Backend Security Architecture

Authentication

Server-side identity

Passwords are hashed with bcrypt using cost factor 12. Successful authentication regenerates the Express session before privileged state is attached.

bcrypt · session.regenerate() · HttpOnly cookies

Authorization

Role enforcement

Permanent-admin and moderator checks execute on protected server routes. UI visibility is not treated as authorization.

requireLogin · requireModerator · requirePermanentAdmin

Request integrity

CSRF and correlation

State-changing HTTP operations require a session-bound CSRF token. Requests receive UUID correlation IDs.

32-byte CSRF token · X-Request-ID

Abuse control

Rate limiting

Authentication endpoints use tighter limits and blocked attempts become structured security events.

express-rate-limit · outcome=blocked

Database

Parameterized SQLite

Application records and security telemetry are stored in SQLite using placeholders for user-controlled values.

SELECT ... WHERE username = ?

Output security

XSS-resistant rendering

EJS escapes normal output. Live chat and avatar bubbles use textContent, with CSP headers in the full backend.

EJS · textContent · Helmet CSP

Uploads

Image validation

Profile images are restricted to PNG, JPEG, and WebP, capped at 512 KB, and checked by binary signature.

allowlist · magic bytes · size cap

Export safety

CSV injection defense

Admin exports neutralize spreadsheet formula prefixes before user-controlled values are written to CSV.

= + - @ neutralization

Forensics

SQL investigation examples

SELECT
    COALESCE(username_snapshot, 'anonymous') AS attempted_user,
    COUNT(*) AS failure_count,
    MIN(created_at) AS first_failure,
    MAX(created_at) AS last_failure
FROM security_events
WHERE event_type = 'auth.login_failed'
  AND created_at >= datetime('now', '-24 hours')
GROUP BY COALESCE(username_snapshot, 'anonymous')
ORDER BY failure_count DESC;
SELECT created_at, event_type, severity, outcome, route, request_id
FROM security_events
WHERE session_ref = ?
ORDER BY created_at ASC;
