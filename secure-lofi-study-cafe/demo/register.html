Shared Registration

User accounts must be created on the live self-hosted server.

GitHub Pages is a static host. It cannot run the Node.js, SQLite, Express-session, or Socket.IO backend required for accounts on separate phones and computers to see one another.

Once the self-hosted server is running, everyone must open the same server URL. Registration there writes to the shared SQLite users table, and Socket.IO publishes realtime presence to every connected room member.
