For safety and moderation, the café records usernames, account activity, chat submissions, music requests, and administrative actions. Passwords, session tokens, precise location, browser history, and unrelated device data are not shown to admins.

Accounts created on this static GitHub Pages build are stored only in the current browser. The full Node.js application authenticates against SQLite using bcrypt password hashes and server-side sessions.
